VIỆT HÓA GAME v0.4.0 – HƯỚNG DẪN (Windows 10/11)

1. Mở VietHoaGame.exe. App tự tìm game trên Steam, Epic, GOG.
   Không thấy game: bấm "+ Thêm game bằng tay" rồi chọn thư mục cài game.
2. Game có Việt hóa: bấm "Cài Việt hóa". App sao lưu file gốc trước khi cài.
3. Gỡ Việt hóa: bấm "Khôi phục bản gốc".
4. Game cập nhật làm mất Việt hóa: dòng trạng thái báo "cần cài lại" – bấm "Cài lại".

GÓI THỬ
  - Nút "Cài gói thử" chỉ thêm file VIET_HOA_THU.txt vào thư mục game, không sửa file nào của game.
  - Dùng để kiểm tra launcher. Bấm "Khôi phục bản gốc" để xóa file đó.

LỖI THƯỜNG GẶP
  - "không ghi được vào thư mục game": tắt game rồi thử lại; game trong Program Files thì
    bấm "Chạy bằng quyền quản trị".
  - Mất bản sao lưu: dùng "Kiểm tra tính toàn vẹn tệp" của Steam / Epic để lấy lại file gốc.

VIỆT HÓA CRIMSON DESERT (game 2.04 trở lên)
  1. Lưu mã Claude trong app Dịch Game (một lần).
  2. Bấm "Việt hóa bằng Claude" ở dòng Crimson Desert -> chọn Đợt 1 hoặc Đợt 2 -> chọn máy dịch (Claude / Offline miễn phí) -> chọn giới hạn tiền -> "Bắt đầu dịch".
  3. Dịch xong bấm "Xuất gói cho DMM" -> file VietHoa_CrimsonDesert.zip nằm ở Desktop.
  4. Mở DMM: Import file zip -> bật -> Mount Mods -> Start Game. Ngôn ngữ game để English.

Dữ liệu của app: %APPDATA%\VietHoaGame
